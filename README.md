## How to Read These

Each project folder follows the same 13-section template (executive summary →
research → strategy → 30-day plan → video → sample content → automation → pricing →
presentation outline → next steps). Start with each folder's `README.md` for the
executive summary and navigation.

*Graphics and video are delivered as detailed concepts, art-direction specs, and
storyboards. a.i. STaRR can render finished assets via Canva and HeyGen as a
production add-on.*
